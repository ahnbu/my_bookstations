# 데모 모드 안내 띠 상단 분리 구현계획

**Goal:** "이 화면은 예시다"라는 **메타 안내**를 서비스 본체에서 떼어내 페이지 최상단 고정 띠로 옮긴다. `DemoLibrary`는 실물 서재 섹션과 구조가 같아지고, 안내는 별도 층에서 계속 보인다.

**Architecture:** 데모 모드 판정을 `hooks/useDemoMode.ts` 하나로 모으고, `App.tsx`와 `MyLibrary.tsx`가 같은 훅을 읽는다. 안내 띠는 `components/DemoModeBanner.tsx`로 분리해 `main` **바깥**, 페이지 첫 요소로 렌더한다. `DemoLibrary` 안의 기존 띠는 제거한다.

**Tech Stack:** Vite 6, React 19, TypeScript 5, Zustand, Tailwind, node:test + Playwright

---

## 1. 배경

선행 작업(`docs/20260818_03_...(실행완료).md`)에서 데모 상단 배너 블록을 안내 띠 1줄로 줄여 [DemoLibrary.tsx:114](../components/DemoLibrary.tsx) 자리에 뒀다. 배포 후 사용자가 두 가지를 지적했다.

### 1-1. 안내가 눈에 띄지 않는다

띠 배경이 `bg-elevated`인데 [index.css:28](../index.css)에서 `var(--card)`이라 라이트 모드 페이지 배경과 거의 같다.

### 1-2. 메타 설명과 서비스 본체가 섞여 있다 (근본 문제)

"이 화면은 예시입니다"는 **화면 자체에 대한 설명**이고, 툴바·카드 목록은 **서비스 본체**다. 층이 다른 두 가지가 같은 컨테이너 흐름에 있으면 양쪽이 동시에 나빠진다.

- 서비스 본체 쪽: 실물 `MyLibrary`에 없는 요소가 서재 섹션에 끼어들어 "실물과 같게" 목표가 깨진다
- 메타 쪽: 안내가 UI의 일부로 읽혀 부각되지 않는다 — 1-1의 증상이 여기서 나온다

색 대비만 올리는 것은 증상 치료다. 층을 분리한다.

### 1-3. 문구가 내용 주장이라 오해 소지가 있다

현재 문구 "이 화면은 예시 서재입니다"는 화면 전체를 예시로 규정한다. 그러나 **비로그인 상태에서도 검색은 실제로 동작한다** — [SearchForm.tsx](../components/SearchForm.tsx)에 세션 의존이 없고, [BookDetails.tsx:272-276](../components/BookDetails.tsx)의 '내 서재에 추가'만 '로그인 후 추가'로 비활성화된다.

띠를 최상단으로 올리면 이 오해가 커지므로, 문구를 **모드 서술 + 범위 한정**으로 바꾼다.

## 2. 사용자 확정 사항

1. **최상단 전체폭 띠로 옮긴다.** 메타 설명과 서비스 본체를 섞지 않는다.
2. 코드 수정량은 판단 기준이 아니다. 설계 원칙을 우선한다.
3. 그 외 세부는 아래 3절 권장안을 따른다.

## 4. 설계

### 4-1. 데모 모드 판정 정본 — `hooks/useDemoMode.ts`

현재 판정은 [MyLibrary.tsx:792-800](../components/MyLibrary.tsx)에만 있다. 띠가 `App.tsx`로 가면 같은 판정을 두 곳이 읽는다. **조건이 갈라지면 띠만 뜨고 데모는 안 뜨는 상태**가 생기므로 훅 하나로 모은다.

```
export type LibraryViewMode = 'library' | 'demo' | 'loggedOut';

export function useDemoMode(): LibraryViewMode
// session 있음                        → 'library'
// session 없음 + hasSignedInBefore()  → 'loggedOut'
// session 없음 + 이력 없음            → 'demo'
```

- 내부에서 `useAuthStore(state => state.session)`과 `hasSignedInBefore()`를 읽는다
- `App.tsx`는 `=== 'demo'`일 때만 띠를 렌더한다
- `MyLibrary.tsx`는 반환값으로 세 화면을 가른다

`hasSignedInBefore()`는 `localStorage` 동기 읽기이므로 렌더 중 호출해도 안전하다. 값이 렌더 도중 바뀌지 않도록 `useState` 초기화로 1회만 읽는다.

### 4-2. 안내 띠 — `components/DemoModeBanner.tsx`

**문구 (확정)**

```
로그인 전 미리보기 — 아래 서재는 예시 데이터입니다 (재고 {DEMO_SNAPSHOT_DATE} 기준)
```

괄호 부분은 `<span className="hidden sm:inline">`으로 감싸 **640px 미만에서는 숨긴다.** 모바일에서 1줄을 유지하기 위해서다. 핵심 메시지("예시 데이터")는 모든 폭에서 남는다.

*근거:*
- "로그인 전 미리보기"가 모드를 서술하고, "아래 서재는"이 예시의 범위를 서재로 한정한다. 1-3의 검색 오해를 문구 자체가 막으므로 "검색은 실제로 동작합니다"를 덧붙이지 않는다
- 재고 기준일은 지금 `DemoLibrary` 하단에 있으나 이 역시 화면에 대한 메타 설명이므로 띠로 옮긴다 (4-4)

**배치와 스타일**

| 항목 | 값 | 근거 |
|---|---|---|
| 위치 | `App.tsx`의 `div.min-h-screen` 첫 자식, `main` **바깥** | `main`은 `max-w-4xl mx-auto px-4 py-8`이라 안에 넣으면 콘텐츠로 읽힌다. 전체폭이어야 별도 층으로 보인다 |
| 고정 | `sticky top-0` | 비고정이면 책 목록까지 스크롤한 순간 안내가 사라져, 관람자가 예시를 실제 서재로 오인할 수 있다 |
| z-index | `z-40` | 모달 `z-50`([WelcomeModal.tsx:89](../components/WelcomeModal.tsx), [AuthModal.tsx:114](../components/AuthModal.tsx))과 토스트 `z-[100]`([Notification.tsx:48](../components/Notification.tsx)) **아래**여야 한다. 모달 위로 띠가 뚫고 나오면 안 된다 |
| 토스트 겹침 | 문구 `text-center` 유지 + 우측 여백 `px-4 sm:px-64` | 토스트는 `fixed top-5 right-5`(상단 20px)이고 띠 높이는 `py-2 text-sm` 기준 약 36px이라 **세로 구간이 겹친다.** 토스트가 `z-[100]`으로 위에 그려지므로 띠 문구가 우측으로 뻗으면 가려진다. 중앙 정렬 + 우측 여백으로 문구를 토스트 영역 밖에 둔다. `Notification`은 공용 컴포넌트이므로 데모 전용 위치 조정을 넣지 않는다 |
| 대비 | `bg-blue-600 text-white` | 1-1의 원인이 `bg-elevated`의 낮은 대비다. 서비스 팔레트 밖의 색을 써서 "서비스가 아닌 층"임을 시각적으로 선언한다. 흰 글자라 다크 모드에서도 동일하게 읽힌다 |
| 정렬 | `text-center text-sm px-4 py-2` | 375px에서 1줄 유지 |
| 테스트 훅 | `data-testid="demo-mode-banner"` | |

헤더는 고정이 아니므로(`components/layout/Header.tsx`의 루트가 `flex ... mb-10`) 스크롤 시 헤더는 올라가고 띠만 남는다. 의도한 동작이다.

### 4-3. `DemoLibrary` 정리

[DemoLibrary.tsx:112-115](../components/DemoLibrary.tsx)의 띠 `div`를 통째로 제거한다.

### 4-4. 하단 재고 기준일 문구도 띠로 옮긴다

[DemoLibrary.tsx:187-189](../components/DemoLibrary.tsx)의 `<p>` — `위 목록은 예시이며, 재고는 {DEMO_SNAPSHOT_DATE} 기준입니다` — 를 **제거**한다.

*근거:* 이 문장은 버튼이 아니라 **화면에 대한 설명**이다. 1-2의 근본 문제와 정확히 같은 종류이므로, 상단 띠만 옮기고 이 문장을 남기면 메타/본체 분리가 절반만 이뤄진다. 내용(재고 기준일)은 4-2의 띠 문구에 흡수했으므로 정보 손실이 없다.

제거 후 `DemoLibrary`에서 `DEMO_SNAPSHOT_DATE` import가 미사용이 되므로 **함께 제거**한다. 대신 `DemoModeBanner`가 `data/demoLibrary`에서 직접 import한다.

남는 구조는 `MyLibraryToolbar` → `BookListContainer` → CTA 버튼으로, 실물 서재 섹션 + 전환 버튼 하나가 된다.
