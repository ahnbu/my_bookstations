## Blocking Issues

- **지적:** 계획 결론은 “못 찾으면 검색 결과로 연결”인데, 구현 규칙은 `status === 'none'`이면 버튼을 숨깁니다.

- **막히는 이유:** 새로 추가한 책에서 사용자가 이용하려던 전자책 이동 경로가 사라집니다. 계획 내부의 완료 동작도 서로 다릅니다.

### 2. 환경 설정 순서대로 진행하면 로컬 검증이 실패합니다

- **막히는 이유:** 작업 6 이전의 카카오 실호출은 키가 없어 실패하고, 변경 전 기준 화면부터 앱 초기화가 막힙니다.
